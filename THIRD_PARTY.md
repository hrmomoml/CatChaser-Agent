# Attribution

This project includes a patch against RoboParty's GPL-3.0 inference code. The exact revision and source links are in docs/SOURCES.md. The GPL license text is included in LICENSE. The external RPO model is not bundled; it retains its CERN-OHL-W-2.0 license. Vendor SDKs, model binaries and third-party binary dependencies are not copied into this repository.

sim_source contains the RPO cat-play program created in this user session. The existing RPO repository and metadata identify its model provenance. The snapshot is used for reference export, with source-model collision masks retained; optional refined collision assets are not bundled. Use the separate mesh inspection report in the user's existing RPO project for that investigation.
